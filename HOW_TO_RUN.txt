1. PREREQUISITES
--------------------------------------------------------------------------------
- Node.js (v18 or higher recommended)
- npm (installed with Node.js)
- Modern Web Browser (Chrome, Safari, Brave, Edge)

--------------------------------------------------------------------------------
2. STEP-BY-STEP RUN INSTRUCTIONS
--------------------------------------------------------------------------------

You will need TWO terminal tabs open (one for Backend, one for Frontend).

----------------------------------
TAB 1: START THE BACKEND API
----------------------------------
1. Open Terminal and navigate to the project directory:
   cd /Users/vasukumar.langdecha/Documents/hackathone/backend

2. Install dependencies (if not already installed):
   npm install

3. Start the Express API server:
   npm start
   (or: node server.js)

-> Backend will start on: http://localhost:3001
-> Configured API Endpoints:
   - POST /api/chat/rag         (Gemini 1.5 Flash + Vector RAG)
   - POST /api/vector-search    (Cosine similarity search)
   - POST /api/scraper/trigger  (Bright Data DCA Collector Trigger)
   - GET  /api/scraper/health   (Proxy pool & health metrics)
   - GET  /api/breaking-diff    (API breaking changes radar)
   - GET  /api/doc-stores       (Managed documentation libraries)


----------------------------------
TAB 2: START THE FRONTEND (REACT + VITE)
----------------------------------
1. Open a NEW Terminal tab and navigate to frontend directory:
   cd /Users/vasukumar.langdecha/Documents/hackathone/frontend

2. Install dependencies (if not already installed):
   npm install

3. Start the Vite React development server:
   npm run dev

-> Frontend will start on: http://localhost:5173


--------------------------------------------------------------------------------
3. OPEN THE APPLICATION
--------------------------------------------------------------------------------
Open your browser and visit:
👉 http://localhost:5173

Vite automatically proxies all `/api` calls to the backend on `http://127.0.0.1:3001`.

--------------------------------------------------------------------------------
5. TROUBLESHOOTING & COMMON COMMANDS
--------------------------------------------------------------------------------
If you see "Error: listen EADDRINUSE: address already in use :::3001" or ":::5173":
Run this command in Terminal to free up the ports:

lsof -ti:3001,5173 | xargs kill -9

Then restart the backend (`npm start`) and frontend (`npm run dev`).
