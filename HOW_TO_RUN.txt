How to run DocuPulse AI locally
-------------------------------

This is pretty straightforward to get running. You just need Node.js installed.

1. Setup the Backend
First, open your terminal and go to the backend folder:
cd backend

Copy the env template:
cp .env.example .env

Open that .env file and add your Bright Data token and your Gemini API Key.
Then install everything and start the server:
npm install
npm start

The backend will start running on http://localhost:3001.

2. Setup the Frontend
Open a second terminal window (leave the backend running) and go to the frontend folder:
cd frontend

Install the packages and run the dev server:
npm install
npm run dev

Now just open http://localhost:5173 in your browser and you're good to go!

Notes for the judges:
When testing the app, try asking it a question about Next.js or LangChain. You'll see it gives line-by-line citations using the data we scraped via our Collector ID.
If you click around the sidebar, you can also see the UI we built to simulate the self-healing process.

If you get a "port in use" error, just kill whatever is on 3001 or 5173 and try again!
