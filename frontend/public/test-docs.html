Create a Charge (v2)

To charge a credit card or other payment source, you create a Charge object.

API Route

POST REQUEST https://api.omnipay.com/v1/charges

Payload Arguments

amount integer REQUIRED

Amount intended to be collected by this payment in cents.

currency string REQUIRED

Three-letter ISO currency code, in lowercase.

Example Request

curl https://api.omnipay.com/v1/charges \
  -u sk_test_YOUR_API_KEY_HERE_123: \
  -d amount=2000
