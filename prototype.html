How do I trigger a DCA collector with self‑healing enabled from Node.js?

DocuPulseVector match 0.94

Pass enable_self_healing: true in the trigger payload. If the target page's markup drifts mid-run, the collector re-derives its selectors from the schema's field prompts instead of failing the job.

node.js
const res = await fetch('https://api.brightdata.com/dca/trigger', {
  method: 'POST',
  body: JSON.stringify([{
    url: 'https://nextjs.org/docs',
    auto_heal: true // re-derive selectors on drift
  }])
});

Next.js 15.0.0Async request headers & cookies migration
Breaking change

The runtime methods cookies(), headers() and params now return Promises and require await.

● Before
import { cookies } from 'next/headers';
const store = cookies();
const token = store.get('token');
● After — live scraped
import { cookies } from 'next/headers';
const store = await cookies();
const token = store.get('token');

Feature update

Setting enable_self_healing: true on a DCA trigger turns on automatic fallback‑selector derivation for that run.

LangChain v0.3.4initialize_agent() retired for bind_tools()
Breaking change

Legacy initialize_agent and AgentType enums are gone. Bind tools directly to the model instead.

● Before
from langchain.agents import initialize_agent, AgentType
agent = initialize_agent(tools, llm,
  agent=AgentType.CHAT_CONVERSATIONAL_REACT)
● After — live scraped
llm_with_tools = llm.bind_tools(tools)
response = llm_with_tools.invoke('...')
